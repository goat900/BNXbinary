# BNXbinary

**BNXbinary — Binary Trading Platform**

BNXbinary is a modern, responsive binary trading platform interface designed for Deriv traders.

## Features

- Trading dashboard
- Auto Trader
- Manual Trader
- Bot Builder
- Bulk Trader
- Digit Scanner
- Signal AI
- Copy Trader
- Charts
- Performance tracking
- Trade History
- Demo trading interface
- Deriv account connection placeholder

## Technology

- HTML5
- CSS3
- JavaScript
- Cloudflare Pages
- GitHub

## Installation

1. Download the BNXbinary project.
2. Extract the ZIP file.
3. Upload all project files to your GitHub repository.
4. Connect GitHub to Cloudflare Pages.
5. Deploy the website.

## Project Structure

- index.html
- styles.css
- app.js
- README.md

Deriv OAuth authentication, live market data and real trading execution require additional secure backend development.
